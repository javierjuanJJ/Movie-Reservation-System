# Feature 003: Showtime Management

## Description
Programming functions and schedules for movies. Management of exhibition dates and halls/salas.

## Endpoints
- GET /api/showtimes
- POST /api/showtimes (Admin)
- GET /api/showtimes/movie/:movieId (protected)
- PUT /api/showtimes/:id (Admin)
- DELETE /api/showtimes/:id (Admin)
