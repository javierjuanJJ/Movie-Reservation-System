# Tech Stack

- **Language**: TypeScript (Node.js 22)
- **Framework**: Express
- **ORM/DB**: PostgreSQL with Prisma
- **Validation**: Zod
- **Authentication**: better-auth
- **Payment**: Stripe
- **Email**: Resend (or SendGrid)
- **SMS**: Twilio
- **Testing**: Native node:test and node:assert
- **Migration**: Prisma Migrate
- **Runtime**: Node.js 22.x
