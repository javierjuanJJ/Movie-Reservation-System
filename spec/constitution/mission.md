# Mission

Build a complete backend for a Movie Reservation System using Spec Driven Development (SDD) with Node.js, Express, TypeScript, and PostgreSQL via Prisma. The system must handle user authentication and roles, movie and showtime management, seat reservations with transactional integrity to prevent overbooking, payment processing via Stripe, and email/SMS notifications.

All code must live in a `backend/` folder following strict separation of concerns: app.js, middlewares/, schemas/, models (Prisma), controllers, routes, and tests using native node:test.
